# pairwise-ragdoll

角色从台阶摔下时关节反折、手脚穿地、起身抽搐：关节限制用欧拉角；碰撞体比骨骼小；PD 增益随质量不变；重力补偿只算根骨；地面接触用单点；主动布娃娃和动画混合硬切；关节驱动目标没限速；碰撞对忽略同链；恢复起身没清速度；固定步长和动画帧不同步。physics/ragdoll.py 是核心，tests/test_ragdoll.py 15个红。要修的是：四元数限制；碰撞体扩张；质量归一增益；全链重力；多点接触；混合斜坡；驱动限速；同链过滤；起身清速；固定步长。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
